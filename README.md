# for-google-labs-jules
All the access to google jules 

## Environment Variables

Make sure to set the following environment variables (or supply them in `.env` based on `.env.example`):
- `MONGODB_URI`: The connection string for your MongoDB database.
- `MONGODB_DB_NAME`: The database name.
- `OPENAI_API_KEY`: API key for OpenAI to perform RAG vector embeddings.
- *Additional API keys for integrations (Claude, Gemini, Instagram, ElevenLabs, etc.) are listed in `.env.example`.*
